يجمع LunaBeat تشغيل الموسيقى المحلية وإنشاء كلمات الأغاني المتزامنة كلمةً بكلمة وتنظيم مكتبة الموسيقى في تطبيق واحد. يمكنك الاستماع بهدوء ومتابعة الكلمات وهي تتكشف مع اللحن، أو تقسيم كلمات أغنية وضبط توقيتها وإضافة الترجمات ومعلومات الغناء الثنائي، ثم تصدير النتيجة لاستخدامها في سير عملك الخاص بكلمات الأغاني.

## الميزات الرئيسية

| الاستخدام | ما يمكنك فعله |
| --- | --- |
| الاستماع إلى الموسيقى المحلية | فحص الملفات الصوتية المحلية وتصفحها حسب الفنان أو الألبوم أو قائمة التشغيل؛ مع دعم التشغيل في الخلفية وأدوات التحكم بالوسائط في النظام وقائمة انتظار التشغيل ومؤقّت الإيقاف. |
| الاستمتاع بالكلمات | معاينة الكلمات كلمةً بكلمة مع السمات الفاتحة والداكنة وإعدادات شريط التشغيل والخلفية؛ وعرض الكلمات على الشاشة الرئيسية وشريط الحالة وعبر اتصال Bluetooth في السيارة. |
| ضبط التوقيت كلمةً بكلمة | استخدام الأزرار الثلاثة بداية / متابعة / نهاية، ثم تحسين التوقيت باستخدام سرعة التشغيل والانتقال الزمني ووضع المتابعة والتراجع والإعادة. |
| تحرير الكلمات | تقسيم الكلمات وفصل المقاطع ودمجها ونقل الأسطر وإزاحة الطوابع الزمنية والتحويل بين الصينية المبسطة والتقليدية وحذف الأسطر الفارغة وضبط الترجمات والغناء الثنائي والأصوات الخلفية. |
| تنظيم الموسيقى | إدارة قوائم التشغيل والمفضلة والأغاني ذات الخمس نجوم؛ ومطابقة الأغلفة والوسوم والكلمات دفعةً واحدة وتحرير البيانات الوصفية وإعادة تسمية الملفات. |

### الاستيراد والتصدير

| المحتوى | الاستيراد | التصدير |
| --- | --- | --- |
| كلمات بنص عادي | مدعوم | — |
| LRC (سطرًا بسطر / كلمةً بكلمة) | مدعوم | مدعوم |
| LRC المحسّن (ELRC) | مدعوم | مدعوم |
| TTML | مدعوم | مدعوم مع الاحتفاظ بمعلومات الغناء الثنائي والأصوات الخلفية |

يمكنك أيضًا البحث عن الكلمات أو استيراد ملف صوتي لبدء الإنشاء. يُنصح باختيار TTML للاحتفاظ بالمعلومات البنيوية مثل الغناء الثنائي والأصوات الخلفية، بينما يناسب LRC عرض الكلمات المعتاد.

## البدء السريع

### الاستماع وتنظيم مكتبة الموسيقى

1. افتح مكتبة الموسيقى وافحص الملفات الصوتية المحلية على جهازك.
2. تصفح حسب الفنان أو الألبوم أو قائمة التشغيل أو المفضلة، ثم اضغط على أغنية لتشغيلها.
3. افتح المشغّل الكامل لتغيير وضع التشغيل وإدارة قائمة الانتظار وعرض الكلمات أو ضبط مؤقّت الإيقاف.
4. لتنظيم الملفات، طابق الوسوم والكلمات دفعةً واحدة أولًا، ثم حرّر الوسوم أو أعد تسمية الملفات.

### إنشاء كلمات أغنية متزامنة كلمةً بكلمة

1. **الاستيراد**: اختر الملف الصوتي، ثم استورد الكلمات كنص عادي أو بصيغة LRC أو ELRC أو TTML. يمكنك أيضًا البحث عن الكلمات.
2. **التحضير**: قسّم الكلمات أولًا، ثم احذف الأسطر الفارغة أو ادمج الكلمات أو حوّل بين الصينية المبسطة والتقليدية. إذا كان التوقيت موجودًا بالفعل، فحاذِه أولًا بإزاحة الخط الزمني كاملًا.
3. **ضبط التوقيت**: شغّل الملف الصوتي واستخدم الأزرار الثلاثة أدناه مع إيقاع كل سطر من الكلمات.
4. **التحسين**: اضغط مرتين على الكلمات للانتقال إليها وإعادة الاستماع. راجع التوقيت باستخدام وضع المتابعة والتراجع والإعادة؛ واضغط مطولًا على وحدة كلمات أو سطر لفصله أو دمجه أو نقله أو تحرير ترجمته.
5. **المعاينة والتصدير**: تحقّق من تأثير العرض كلمةً بكلمة؛ واختر LRC للعرض المعتاد أو TTML لمعلومات الغناء الثنائي والأصوات الخلفية.

| الزر | الإجراء |
| --- | --- |
| بداية | يضبط وقت بداية الوحدة الحالية ويبقى عندها. |
| متابعة | يضبط وقت نهاية الوحدة الحالية وينتقل إلى التالية، ويضبط أيضًا وقت بداية الوحدة التالية. |
| نهاية | يضبط وقت نهاية الوحدة الحالية وينتقل إلى التالية، ويترك وقت بداية الوحدة التالية لضبطه لاحقًا. |

التسلسل المقترح: `بداية → متابعة → متابعة → … → نهاية`، ويُكرّر لكل سطر.

<details>
<summary>نصائح لضبط توقيت الكلمات</summary>

- تعرض أعمدة الوقت والنص وقت البداية والكلمات ووقت النهاية والترجمة.
- اضغط مرة واحدة على وحدة كلمات لتحديدها، ومرتين للانتقال إلى وقت بدايتها وإعادة الاستماع.
- يدعم التطبيق الرجوع / التقديم السريع والتشغيل / الإيقاف المؤقت وتغيير السرعة والانتقال إلى وقت محدد.
- اضغط على وقت التشغيل للدخول إلى وضع المتابعة؛ واضغط على الوقت في منطقة ضبط التوقيت لتحديد وجهة انتقال مخصصة.
- يمكن ضبط الغناء الثنائي إلى اليسار (الصوت الرئيسي) أو اليمين (الصوت الثاني) أو الخلفية (الأصوات الخلفية)، ثم تصديره بصيغة TTML.

</details>

## الأسئلة الشائعة

<details>
<summary>هل أختار LRC أم TTML؟</summary>

اختر LRC لعرض الكلمات المعتاد، أو TTML للاحتفاظ بالمعلومات البنيوية مثل الغناء الثنائي والأصوات الخلفية. يمكنك التحقق من تأثير العرض كلمةً بكلمة في المعاينة قبل التصدير.

</details>

<details>
<summary>ما الذي ينبغي مراعاته عند تصدير كلمات الغناء الثنائي وتشغيلها؟</summary>

يُفضّل تصدير معلومات الغناء الثنائي والأصوات الخلفية بصيغة TTML وعرضها في مشغّل يدعم هذه التأثيرات. يعتمد العرض الفعلي على دعم المشغّل لصيغة الكلمات والمعلومات المرتبطة بها.

</details>

<details>
<summary>كيف أعدّل الكلمات إذا كانت كلها مبكرة أو متأخرة؟</summary>

أزح الطوابع الزمنية لمحاذاة التوقيت كاملًا أولًا، ثم عد إلى شاشة ضبط التوقيت لتحسين الأجزاء الفردية.

</details>

<details>
<summary>من أين أبدأ إذا كانت هذه أول مرة أضبط فيها توقيت الكلمات؟</summary>

أكمل تقسيم الكلمات وتنظيف النص قبل البدء بضبط التوقيت. اختر أغنية تعرفها، واستخدم «بداية → متابعة → … → نهاية» لكل سطر، ثم أعد الاستماع وأجرِ تعديلات طفيفة.

</details>
