LunaBeat รวมการเล่นเพลงในเครื่อง การสร้างเนื้อเพลงแบบจับเวลาทีละคำ และการจัดระเบียบคลังเพลงไว้ในแอปเดียว คุณสามารถฟังเพลงอย่างสบายใจและดูเนื้อเพลงที่แสดงไปตามท่วงทำนอง หรือแบ่งคำ จับเวลา เพิ่มคำแปลและข้อมูลร้องคู่ให้กับเพลง แล้วส่งออกไปใช้ในขั้นตอนการทำเนื้อเพลงของคุณเอง

## ฟีเจอร์หลัก

| การใช้งาน | สิ่งที่ทำได้ |
| --- | --- |
| ฟังเพลงในเครื่อง | สแกนไฟล์เสียงในเครื่องและเลือกดูตามศิลปิน อัลบั้ม หรือเพลย์ลิสต์ รองรับการเล่นเบื้องหลัง การควบคุมสื่อของระบบ คิวเล่น และตั้งเวลาหยุด |
| ดื่มด่ำกับเนื้อเพลง | ดูตัวอย่างเนื้อเพลงทีละคำ พร้อมธีมสว่างและมืด การตั้งค่าแถบควบคุมและพื้นหลัง รองรับเนื้อเพลงบนหน้าจอหลัก แถบสถานะ และผ่าน Bluetooth ในรถยนต์ |
| จับเวลาทีละคำ | ใช้สามปุ่ม เริ่ม / ต่อเนื่อง / จบ แล้วปรับเวลาอย่างละเอียดด้วยความเร็วการเล่น การข้ามไปยังเวลา โหมดติดตาม เลิกทำ และทำซ้ำ |
| แก้ไขเนื้อเพลง | แบ่งคำ แยกและรวมเนื้อเพลง ย้ายบรรทัด เลื่อนเวลาทั้งชุด แปลงภาษาจีนตัวย่อและตัวเต็ม ลบบรรทัดว่าง และตั้งค่าคำแปล ร้องคู่ และเสียงประสาน |
| จัดระเบียบเพลง | จัดการเพลย์ลิสต์ เพลงโปรด และเพลงห้าดาว จับคู่ภาพปก แท็ก และเนื้อเพลงแบบกลุ่ม แก้ไขข้อมูลเมตา และเปลี่ยนชื่อไฟล์ |

### นำเข้าและส่งออก

| เนื้อหา | นำเข้า | ส่งออก |
| --- | --- | --- |
| เนื้อเพลงข้อความล้วน | รองรับ | — |
| LRC (ทีละบรรทัด / ทีละคำ) | รองรับ | รองรับ |
| LRC แบบเพิ่มความสามารถ (ELRC) | รองรับ | รองรับ |
| TTML | รองรับ | รองรับ โดยคงข้อมูลร้องคู่และเสียงประสาน |

คุณยังสามารถค้นหาเนื้อเพลงหรือนำเข้าไฟล์เสียงเพื่อเริ่มสร้างได้ แนะนำให้เลือก TTML เมื่อต้องการคงข้อมูลโครงสร้าง เช่น การร้องคู่และเสียงประสาน ส่วน LRC เหมาะกับการแสดงเนื้อเพลงทั่วไป

## เริ่มต้นใช้งาน

### ฟังเพลงและจัดระเบียบคลังเพลง

1. เปิดคลังเพลงแล้วสแกนไฟล์เสียงในเครื่องของคุณ
2. เลือกดูตามศิลปิน อัลบั้ม เพลย์ลิสต์ หรือเพลงโปรด แล้วแตะเพลงเพื่อเล่น
3. เปิดเครื่องเล่นแบบเต็มเพื่อเปลี่ยนโหมดเล่น จัดการคิว ดูเนื้อเพลง หรือตั้งเวลาหยุด
4. เมื่อต้องการจัดระเบียบไฟล์ ให้จับคู่แท็กและเนื้อเพลงแบบกลุ่มก่อน แล้วจึงแก้ไขแท็กหรือเปลี่ยนชื่อไฟล์

### สร้างเนื้อเพลงทีละคำให้กับเพลงหนึ่งเพลง

1. **นำเข้า**: เลือกไฟล์เสียง แล้วนำเข้าเนื้อเพลงข้อความล้วน LRC, ELRC หรือ TTML หรือค้นหาเนื้อเพลงก็ได้
2. **เตรียมเนื้อเพลง**: แบ่งคำก่อน แล้วลบบรรทัดว่าง รวมเนื้อเพลง หรือแปลงภาษาจีนตัวย่อและตัวเต็ม หากมีเวลาอยู่แล้ว ให้เลื่อนไทม์ไลน์ทั้งชุดเพื่อปรับให้ตรงก่อน
3. **จับเวลา**: เล่นเสียงแล้วใช้สามปุ่มด้านล่างตามจังหวะของเนื้อเพลงแต่ละบรรทัด
4. **ปรับละเอียด**: แตะเนื้อเพลงสองครั้งเพื่อข้ามกลับไปฟัง ตรวจสอบเวลาด้วยโหมดติดตาม เลิกทำ และทำซ้ำ กดหน่วยเนื้อเพลงหรือบรรทัดค้างไว้เพื่อแยก รวม ย้าย หรือแก้ไขคำแปล
5. **ดูตัวอย่างและส่งออก**: ตรวจสอบเอฟเฟกต์ทีละคำ เลือก LRC สำหรับการแสดงผลทั่วไป หรือ TTML เมื่อต้องการข้อมูลร้องคู่และเสียงประสาน

| ปุ่ม | การทำงาน |
| --- | --- |
| เริ่ม | ตั้งเวลาเริ่มของหน่วยปัจจุบันและยังอยู่ที่หน่วยนั้น |
| ต่อเนื่อง | ตั้งเวลาจบของหน่วยปัจจุบันแล้วไปยังหน่วยถัดไป พร้อมตั้งเวลาเริ่มของหน่วยถัดไปด้วย |
| จบ | ตั้งเวลาจบของหน่วยปัจจุบันแล้วไปยังหน่วยถัดไป โดยปล่อยเวลาเริ่มของหน่วยถัดไปไว้ตั้งภายหลัง |

ลำดับที่แนะนำ: `เริ่ม → ต่อเนื่อง → ต่อเนื่อง → … → จบ` ทำซ้ำสำหรับแต่ละบรรทัด

<details>
<summary>เคล็ดลับการจับเวลา</summary>

- คอลัมน์เวลาและข้อความประกอบด้วยเวลาเริ่ม เนื้อเพลง เวลาจบ และคำแปล
- แตะหน่วยเนื้อเพลงหนึ่งครั้งเพื่อเลือก หรือแตะสองครั้งเพื่อข้ามไปยังเวลาเริ่มของหน่วยนั้นและฟังอีกครั้ง
- รองรับย้อนกลับ / กรอไปข้างหน้า เล่น / หยุดชั่วคราว ปรับความเร็ว และข้ามไปยังเวลาที่กำหนด
- แตะเวลาเล่นเพื่อเข้าสู่โหมดติดตาม แตะเวลาในพื้นที่จับเวลาเพื่อกำหนดจุดที่ต้องการข้ามไป
- ตั้งการร้องคู่เป็นด้านซ้าย (เสียงหลัก) ด้านขวา (เสียงที่สอง) หรือพื้นหลัง (เสียงประสาน) แล้วส่งออกเป็น TTML ได้

</details>

## คำถามที่พบบ่อย

<details>
<summary>ควรเลือก LRC หรือ TTML?</summary>

เลือก LRC สำหรับการแสดงเนื้อเพลงทั่วไป หรือ TTML เพื่อคงข้อมูลโครงสร้าง เช่น การร้องคู่และเสียงประสาน สามารถตรวจสอบเอฟเฟกต์ทีละคำในหน้าตัวอย่างก่อนส่งออกได้

</details>

<details>
<summary>ควรระวังอะไรเมื่อส่งออกและเล่นเนื้อเพลงร้องคู่?</summary>

แนะนำให้ส่งออกข้อมูลร้องคู่และเสียงประสานเป็น TTML และเปิดดูในเครื่องเล่นที่รองรับเอฟเฟกต์เหล่านี้ การแสดงผลจริงขึ้นอยู่กับการรองรับรูปแบบเนื้อเพลงและข้อมูลที่เกี่ยวข้องของเครื่องเล่น

</details>

<details>
<summary>หากเนื้อเพลงทั้งหมดเร็วหรือช้าไป ควรปรับอย่างไร?</summary>

เลื่อนเวลาทั้งชุดเพื่อปรับให้ตรงก่อน แล้วกลับไปยังหน้าจับเวลาเพื่อปรับแต่ละช่วงอย่างละเอียด

</details>

<details>
<summary>หากจับเวลาเป็นครั้งแรก ควรเริ่มจากตรงไหน?</summary>

แบ่งคำและจัดข้อความให้เรียบร้อยก่อนเริ่มจับเวลา เลือกเพลงที่คุ้นเคย ใช้ “เริ่ม → ต่อเนื่อง → … → จบ” สำหรับแต่ละบรรทัด แล้วฟังซ้ำและปรับเล็กน้อย

</details>
